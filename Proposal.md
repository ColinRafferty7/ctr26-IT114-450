## Project Name: Go Fish
### Project Summary: Group “Go Fish” (2+ players). Players take turns (round-robin) to ask another player if the target player has a specific card in hand (limited to the cards in the asking player’s hand). If they do, all copies are returned to the asker; otherwise, the asker draws 1 card from the deck. Session ends when a player gets a set number of pairs/sets.
